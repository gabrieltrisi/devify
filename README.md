## ✨ Sobre

**Devify** é a página institucional de um estúdio de tecnologia que constrói **sistemas, automações e soluções de IA** sob medida para empresas — do problema à solução pronta para operar. A landing comunica a proposta com uma narrativa clara e microinterações que dão vida à navegação.

## 🧱 Stack

| Camada | Tecnologias |
|---|---|
| **Framework** | Next.js (App Router), React, TypeScript |
| **Estilo** | Tailwind CSS |
| **Animação** | Framer Motion |
| **Ícones** | Lucide |
| **Infra** | Vercel (CI/CD via GitHub) |

## 🎯 Destaques

- 🎬 **Microinterações e animações** de scroll com Framer Motion.
- 📱 **Totalmente responsiva** — mobile-first.
- ⚡ **Performance** com o App Router do Next.js.
- 🧭 **Narrativa de conversão** — seções que levam da dor à chamada para ação.

## 🚀 Rodando localmente

```bash
npm install
npm run dev   # http://localhost:3000
```
